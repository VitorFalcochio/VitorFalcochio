## 🚀 What I'm Building

### 👁️ CAMPEX

**Turning cameras into operational intelligence.**

CAMPEX transforms existing security cameras into sources of real-time operational data using **computer vision and AI**.

Instead of cameras being used only to record footage, CAMPEX enables companies to understand what is happening inside their operations.

`Computer Vision` `AI` `FastAPI` `Python` `Edge Processing` `Analytics`

---

### 🤖 CREW

**A digital workforce for companies.**

CREW explores a future where companies can deploy specialized **AI-powered digital workers** capable of executing tasks across different systems and workflows.

The goal is to move beyond traditional chatbots toward autonomous software workers that can **understand, act and execute**.

`AI Agents` `Automation` `Digital Workers` `SaaS` `LLMs`
